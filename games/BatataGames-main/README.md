# Batata Games

Base estática pronta para GitHub + Vercel.

## Arquivos principais

- `index.html` → home
- `jogos.html` → catálogo
- `jogo.html` → página individual do jogo
- `css/style.css` → estilo premium roxo/escuro
- `js/games.js` → base dos jogos
- `js/main.js` → home + catálogo
- `js/jogo.js` → player individual

## Observação importante

Essa base usa links de jogos externos. Então ela funciona, mas não é independente de verdade.
Se um link morrer, o layout continua vivo e o jogo quebra.
