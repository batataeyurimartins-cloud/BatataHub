Como importar no VEXcode VR

Esse tutorial mostra o caminho básico para abrir um arquivo .vrblocks e começar a usar os projetos no VEXcode VR.

  1. 01

    Baixe o projeto

    Primeiro, volte para a página inicial e clique no projeto que você quer baixar. O arquivo .vrblocks precisa ficar salvo no seu computador.

  2. 02

    Abra o VEXcode VR

    Entre no VEXcode VR no navegador e espere a interface carregar por completo antes de tentar importar o projeto.

  3. 03

    Importe o arquivo

    Procure a opção de abrir/importar projeto e selecione o arquivo .vrblocks que você baixou. Depois disso, o script deve aparecer na área de edição.

  4. 04

    Teste e rode

    Depois de importar, confira se tudo abriu certo e execute o projeto para ver o comportamento do robô.
