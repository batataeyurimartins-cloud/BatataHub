Como usar

Passo a passo

Como rodar a engine roxa do Batata Hub:

1

Copie o código

Use o botão principal de copiar para salvar o injetor.

2

Abra a página do Quiz

Vá até a tela onde as perguntas e o botão de resposta aparecem.

3

Injete o Hub

Abra o Console (F12), cole o código e dê Enter (ou use o favorito).

4

Configure e Inicie

Ajuste o delay em ms, clique em Initialize Engine e acompanhe os pontos.

Aviso

Contador em Alta Velocidade

Se você colocar um delay muito baixo, a pontuação na interface preta pode bugar ou dessincronizar do servidor, mas os cliques continuam rodando no limite do overclock.

Suporte

Reportar Bugs

Se o sistema travar ou sumir com a interface flutuante, use o botão de Reset All ou avise a rapaziada direto no dece.
